Web UI is an open source web component framework written in plain JavaScript, with an optional Rust WebAssembly worker for heavy work. It powers every Stoic Dreams website and the Task Proxy desktop app.

There is no build step for your UI. Add a tag such as <webui-cards> to a page and the component loads itself from the CDN. Pages can be written in markdown, and data binding with data-subscribe and data-trigger attributes connects components without glue code.

Get Started Components View on GitHub

What you get

App shells, drawers, tabs, cards, dialogs, forms, code blocks, galleries, and more, each loaded only when a page uses it. Write pages in markdown, mixed with HTML and components, and the framework routes to them. Share state between components through named keys, saved to browser storage when you want it kept. A built-in icon set with shapes, borders, rotation, and themes, all drawn from one set of paths. Keyboard support, focus styles, and screen reader names are part of each component. Long-running and heavy work runs in Rust compiled to WebAssembly, in a worker that keeps the page responsive.
