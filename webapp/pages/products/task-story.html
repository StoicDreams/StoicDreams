Task Story is project management for software teams that ship in short, continuous iterations. Define the problem first, try more than one solution, and publish a story of what shipped and what you dropped.

It is free for one developer. Team plans add a shared space and a seat for each teammate.

How it works

1. Define the problem

Start with what is wrong, not with how to fix it. Each problem has room for who has it, what it is, where and when it happens, why it matters, and how to reproduce it.

2. Try more than one solution

Add as many solutions as the problem deserves. Each one carries its own investigation, testing, and development notes, and is linked to the problem by a tag.

3. Publish the story

When the work is done, mark which solutions you implemented and which you dropped, and Task Story turns it all into a single story.

4. Keep the history

Stories keep the problem, the solutions that shipped, and the ones you dropped, with the notes that explain why. When someone later asks why it works this way, the answer is already written down.

The method behind it

Task Story follows Continuous Agile Software Engineering (CASE), the way we work at Stoic Dreams: short iterations, problems before solutions, and learning from every decision, including the ones you dropped.
